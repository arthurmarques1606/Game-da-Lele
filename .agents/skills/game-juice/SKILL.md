---
name: game-juice
description: Adiciona efeitos visuais, partículas, animações suaves e áudio procedural via Web Audio API em jogos HTML5.
---
Sempre que implementar melhorias visuais ou sonoras neste jogo:
1. Use a Web Audio API nativa (oscillators/gain) para criar sons sem depender de arquivos .mp3 externos.
2. Adicione feedback visual imediato (tremor leve de tela, partículas, transições CSS suaves) em toda interação do jogador.
3. Garanta que o layout seja 100% responsivo para telas de celular (touch events e viewport travado).
